# Project instructions

## Commit conventions

Small, meaningful, conventional commits (`feat(meals): add offline meal entry with sync queue`,
`fix(calculation): correct meal rate rounding`) — never one giant commit per phase. No AI
co-author trailer is added to commits in this repository.

Commit after every change, without waiting to be asked: as soon as a change (a feature, a fix,
a small tweak) is complete and verified, create its commit before moving on, split into
separate commits along the same small/meaningful/conventional lines above rather than batching
unrelated changes into one commit at the end.
